# 🌟 Littlestar Studio

**A beginner-friendly programming language with 163+ built-in functions.**

Write beautiful code with English-like syntax — right in your browser. No installations needed!

## 🚀 Try It Now

**[Launch Littlestar Studio](https://paschal6.github.io/littlestar-app/app.html)**

## ✨ Features

- 📝 **163+ built-in functions** — math, strings, arrays, statistics, and more
- 🎨 **Syntax highlighting** — beautiful colored code editor
- 📐 **Geometry** — area, perimeter, volume for 19 shapes
- 💰 **128 currencies** — convert between any world currency
- 📏 **44 unit types** — length, mass, time, data, speed, angles
- 🧮 **Quadratic & cubic solvers** — solve equations instantly
- ➗ **Fraction converter** — decimal to proper/improper fractions
- 🖼️ **Image support** — display images in the console
- 🌐 **Web output** — build HTML/CSS/JS pages
- 🗄️ **Native databases** — store and query structured data
- 🎮 **Interactive programs** — input dialogs for user interaction
- 📱 **Works on mobile** — responsive design for all devices
- 💾 **Auto-save** — your code is saved automatically
- 📥 **Import/Export** — save and load .lstar files
- 🎯 **20+ examples** — learn by exploring

## 📖 Quick Start

```littlestar
module littlestar:

    spark main(1):
        display("Hello, World!")
        shine("Welcome to Littlestar!")

        declare name = "Alice"
        make age = 25

        when age >= 18:
            glow("You're an adult, {name}!")
        otherwise:
            display("Still young!")

    spark print:
        main(1)

module littlestar:

    spark main(1):
        display("Square root: {sqrt(144)}")
        display("Fibonacci: {fibonacci(10)}")
        display("Quadratic: {quadratic(1, -5, 6)}")
        display("Circle area: {round(area(circle, 5), 2)}")
        display("Fraction: {properFraction(2.75)}")

    spark print:
        main(1)

module littlestar:

    spark main(1):
        letarr scores = 85, 92, 78, 95, 88, 76, 91
        display("Average: {avg(scores)}")
        display("Median: {median(scores)}")
        display("Std Dev: {round(stddev(scores), 2)}")

    spark print:
        main(1)

module littlestar:

    spark main(1):
        toHtml("<h1>Hello Web!</h1>")
        toHtml("<p>Built with Littlestar</p>")
        toCss("body { background: #1a1a2e; color: white; padding: 40px; text-align: center; }")
        toCss("h1 { color: #F5A623; }")

    spark print:
        main(1)
